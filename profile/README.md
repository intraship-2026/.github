# IntraShip 2026

**Intrapreneur (Pvt.) Ltd. AI & Tech Internship Program, 2026 cohort**

IntraShip is a structured, mentor-led internship where interns learn by doing: real assignments, real projects and professional engineering practice (Jira, Git, code review and technical documentation).

## Tracks

| Track | Focus |
|---|---|
| AI & Automations With Python | Python automation, LLM-powered agents and workflows, APIs, data handling and testing of AI features. |
| CyberSecurity & Penetration Testing | Web and network penetration testing methodology, vulnerability assessment, CVSS scoring and professional reporting, done ethically in lab environments only. |
| Data Science SQL & NoSQL | Relational and NoSQL data modelling, SQL, ETL pipelines, data quality and introductory analytics / ML on clean data. |
| Frontend Development & JS Frameworks | Modern JavaScript/TypeScript, React and Next.js (App Router), accessible responsive UI, API integration and frontend testing. |
| SQA & Automation Testing | Software testing fundamentals, test design techniques, test cases and bug reports, and UI / API test automation. |

## How we work

- **Planning & reviews:** each track has its own Jira space with an assignment review workflow.
- **Code & documents:** each track has three private repositories in this organization: `assignments`, `projects` and `rnd`.
- **Contributions:** interns have read access and contribute through **fork + pull request**; mentors review and merge.
- **Standards:** see the program handbook (members only).

Repositories in this organization are private to program members.
