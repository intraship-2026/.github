# Code of Conduct

IntraShip is a professional learning environment. All interns, mentors and staff are expected to:

- **Be respectful.** Critique work, not people. Give and receive feedback constructively.
- **Be honest.** Submit your own work. Credit sources, images and code you reuse. Disclose AI assistance as described in the handbook.
- **Be responsible.** Keep credentials, client data and other interns' work private. Security testing is allowed only on authorised lab targets.
- **Be collaborative.** Help others learn, but do not share assignment answers or deliverables.

Harassment, plagiarism, sharing of deliverables, or unauthorised security testing may lead to removal from the program.

Report concerns privately to the IntraShip Program Lead at intraship@intra-preneur.com.
